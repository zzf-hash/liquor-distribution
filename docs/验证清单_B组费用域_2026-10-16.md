## 1. 费用台账与 EXPENSE 审批线（M4-3 / M10-3）

| # | 命令 | 预期 |
|---|---|---|
| 1.1 | `curl -s "$BASE/expenses/summary" -H "Authorization: Bearer $TOKEN" \| jq .data` | 本月含办公 800（pendingTotal）；切 `?month=<上月>`：油费 360 + 办公 150 + 陈列 500，`paidTotal=1010`，`offsetTotal=500` |
| 1.2 | `curl -s "$BASE/expenses?month=<上月>" -H "Authorization: Bearer $TOKEN" \| jq '.data.items[] \| {no:.expenseNo,status,payMode}'` | FY-DEMO-0001/0002=PAID(CASH)，FY-DEMO-0003=PAID(AR_OFFSET) |
| 1.3 | 新建并走完整审批：`POST /expenses`（`{"category":"OFFICE","title":"验证单","amount":88}`，clerk token 建、owner token 批） | 创建返回 PENDING_APPROVAL + approvalId；审批中心出现 EXPENSE 待办；owner `POST /approvals/<id>/decide {"action":"approve","opinion":"ok"}` 后 expense → APPROVED；`POST /expenses/<id>/pay` → PAID |
| 1.4 | 金额路由（D01）：clerk 建一笔 amount=3000 → clerk 自批 `decide` 应 **403**（超阈值仅老板）；owner 批 → APPROVED | 阈值默认 2000（special_approve_threshold） |
| 1.5 | 申请人回避：clerk 建的 800 单，clerk 自己 `decide` → **403**（不可审批自己发起的申请） | 2026-10 审查修复口径保持 |

## 5. 审批联动与超时（D01 语义）

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | clerk 建费用单后立即 `POST /expenses/<id>/cancel {"reason":"x"}` → 再去 decide 该审批 | 取消成功；decide **409**（实体状态闸拦截，不复活） |
| 5.2 | 审批驳回（owner reject） | expense → REJECTED；再 pay → 409 |
| 5.3 | （可选）把审批单挂起 >24h 后访问审批列表 | EXPIRED_24H 联动：expense → CANCELLED |

## 6. 端上人工项

- **管理端「费用中心」**（新菜单，owner/clerk）：台账四笔演示数据 + 月份/科目/状态过滤 + 新建（客户级科目出现冲抵货款选项）+ 已批单「执行冲抵/付款」+ 费用汇总卡
- **开瓶费政策 Tab**：配置商品（回/不回瓶盖模式切换、兑付比例）；**瓶盖回收 Tab**：seed 待确认单 → 确认兑付（选冲抵/现金）→ 跳审批中心
- **小程序（rep1 登录）**：工作台新「🍾 瓶盖回收」磁贴 → 选客户加行提交 → 回收单列表状态流转
- **审批中心**：出现 EXPENSE 线待办（FY-DEMO-0004 + 回收确认生成的单），金额路由提示「内勤可批/仅老板」

## 已知边界（非缺陷）
- 开瓶费计提瓶数取「当期签收订单行」口径（SIGNED/SETTLED，按 signedAt 入期）；退货不回算（与绩效口径一致，如需回算属 C 组引增强）
- 签名式 voucherUrl 仍为 base64 内联过渡（对象存储未接）
- EXPENSE 审批超时退回 = CANCELLED（重报而非复活），与采购/调价的 DRAFT 回退不同——费用单重建成本低
