# 订货商城 · 开发任务书（MVP 分期）v1.0

> 2026-09-21 · 依据《订货商城_业务需求梳理_v1.md》（需求基线）与《酒类分销全链路 AI 整合方案 v0.3》
> 用法：一期为细粒度（可直接进迭代排期）；二期中粒度（开工前一周拆细）；三期为占位清单。
> 技术基线（对齐方案 v0.3，最终以技术决策会为准）：全栈 TypeScript · NestJS + Prisma · PostgreSQL + Redis · React AntD 管理后台 · Taro 小程序/H5 · Docker Compose

---

## 0. 里程碑总览

| 里程碑 | 内容 | 建议周期 | 出口标准 |
|---|---|---|---|
| M0 前置 | 域名 ICP 备案 / 小程序账号 / 服务器采购 / 待确认问题冻结 | 并行 1-2 周 | 备案已提交、账号到手、Q 清单有结论 |
| M1 一期主线 | 接单 → 出库 → 签收 → 销账 全流程 | 6~8 周 | 全流程停 Excel，一线试用通过 |
| M2 二期管控 | 审批 / 退货 / 采购 / 绩效 / 对账 | +6~8 周 | 管控闭环、账实相符 |
| M3 三期 AI | 转单 / 对账 / 预测，按 ROI 滚动 | 滚动 | 逐项单独验收 |

> 周期说明：方案 v0.2 的「6 周上线」对应本任务书 WS-0~WS-5 骨架；需求基线新增了信用拦截、回包装回填、账期提醒、电子单据 6 个月等硬需求，故一期按 6~8 周排。**网签/非网签占比（Q3）是最大浮动项**。

## 1. 一期（P0 · 主线跑通）

### WS-0 脚手架与横切面

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T01 | Monorepo 脚手架 | apps/api · admin · mini + packages/shared；docker-compose 本地一键起 | 空项目跑通登录→示例页 |
| P0-T02 | 认证与 RBAC | 五角色：企业主/业务员/内勤出纳/仓配/客户；tenant_id 由 Prisma 中间件统一注入 | 越权请求 403；业务表全带 tenant_id |
| P0-T03 | 操作审计日志 | 改价、信用拦截放行、销账、抹零等关键动作留痕 | 日志可按人/时间/单据追溯 |

### WS-1 主数据

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T10 | 商品档案 | 品类（白酒/啤酒/红酒/洋酒/饮料）、规格箱·瓶、整散换算、条码、首字搜索 | 下单整散自动换算；首字搜索可用 |
| P0-T11 | 五级价 + 一客一价 | 成本/一批/二批/终端供货/零售指导；**价格快照写入订单明细** | 调价后历史订单金额不变 |
| P0-T12 | 客户档案 + 开户流程 | F1 四步：业务员录入→内勤确认→生成→老板终审；档案含账期/额度/收货时段 | 终审通过前客户不可下单 |
| P0-T13 | 存量迁移 | Excel 批量导入商品/客户/期初库存/期初应收（历史应收） | 差异报表零未解释项，商户签字确认 |

### WS-2 订单主线

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T20 | 三入口接单 | 内勤开单 / 业务员代下单 / 客户商城下单（文字） | 三入口进同一订单池，状态一致 |
| P0-T21 | 审单预检 | 四要素：客户有效（信用/欠款）、价格（专属价）、库存可满足、达起送量 | 超额自动拦截并留痕；老板特批可放行 |
| P0-T22 | 出库 | 拣货单批次先进先出 + 复核 | 出库生成库存流水，批次可追溯 |
| P0-T23 | 签收 | 电子网签 + 回包装品类数量回填 | 未签收订单不可销账 |
| P0-T24 | 非网签双轨 | 后台打印送货单留客户联 + 内勤回录（打印机型号待 Q3） | 打印单↔系统单一致 |
| P0-T25 | 改单/取消/拒收 | 配送前拦截、配送中协商；状态回滚 + 库存回冲 | 拒收后库存与订单状态正确回滚 |

### WS-3 应收与销账

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T30 | 应收台账 | 账期自定义、到期/超期列表 | 账龄列表与手工核对一致 |
| P0-T31 | 收款销账 | F9：业务员上报→内勤录入→销账→清账通知推送 | 销账后客户收到通知、余额正确 |
| P0-T32 | 电子单据 | 未结一览；已结保留 6 个月后归档 | 归档后客户不可见、后台可审计恢复 |

### WS-4 老板看板

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T40 | 四问看板 | 今日卖多少收多少 / 谁欠钱 / 什么货快没了 / 哪个业务员强 | 数据延迟 ≤ 1 分钟 |

### WS-5 客户小程序

| ID | 任务 | 要点 | 验收标准 |
|---|---|---|---|
| P0-T50 | 商城下单 | 商品 + 专属价 + 购物车 + 文字下单 | 客户自助下单直接进订单池 |
| P0-T51 | 客户侧服务 | 账期自动提醒 / 未结单据一览 / 已结查 6 个月 | 提醒按账期前 N 天触发（N 可配） |

**一期验收门**：全流程停 Excel；内勤接单（录单到出库指令）≤ 1 分钟；任意单据可从订单追溯到签收凭证与收款记录。

## 2. 二期（P1 · 管控与效率）

| ID | 模块 | 范围 | 验收标准 |
|---|---|---|---|
| P1-T01 | 审批中心 | 5 条审批线统一：客户价格/特单/采购/运营费/调价；待办消息推送 | 每条线发起→审批→留痕闭环（特单归属待 Q1） |
| P1-T02 | 特单 | F8：全员下单（品名/数量/价格/配送时间/地址定位/联系人/收款人及时间）+ 婚宴宴席单 | 特单价格审批通过后才能出货 |
| P1-T03 | 退货销户 | F10 全流程 + R4「只多不少」 | 退货后应收余款自动重算 |
| P1-T04 | 回包装闭环 | 有单回填 + F11 无单回包装 + 周转箱押金台账 | 押金账实相符 |
| P1-T05 | 调价引擎 | F7 + 存货增值/贬值处理 + 客户价联动 | 审批通过一键生效，自动出存货变动单 |
| P1-T06 | 采购双流程 | F3 先付 / F4 后付（审批节点位置不同）+ 成本价录入 + 一键采购明细 | 两种流程节点顺序正确 |
| P1-T07 | 盘点报损 | 抽盘 + 月末大盘，差异报损审批 | 差异经审批后自动调账 |
| P1-T08 | 优惠三式 | 随单赠 0-10 送 0-10 / 除瓶箱后 5%-50% 返利 / 定扣货款（口径待 Q2）+ 开瓶费两态 | 月末返利自动核算（货补/票折） |
| P1-T09 | 绩效工资 | 三指标（月新客户/月拜访/月销售·以回款计）+ 底薪绩效 + 工资表一键生成 | 每笔绩效可追溯到源单据（归属规则待 Q8） |
| P1-T10 | 月结对账 | 对账单生成→推送客户确认→差异处理（漏单/价格/赠品/退货四类）→核销 | 无系统时 1-3 天的流程压到当日完成 |
| P1-T11 | 一键报表 | 月报表 / 库存表 | 口径与台账一致，一键出表 |
| P1-T12 | 语音/照片转单 | ASR + LLM → 订单草稿（可编辑兜底）；口语容错：别名/量词/「老价格」→专属价/来电反查 | 草稿准确率 ≥ 90%，人工确认后入池 |
| P1-T13 | 拜访管理 | 标准八步骤 + 水印相机打卡 + 陈列照片 + ABC 级拜访频率 | 打卡带时间/定位/水印，不可篡改 |

## 5. 前置依赖与风险

1. **M0 长周期项立即启动**：域名 ICP 备案（1-2 周）、小程序认证、服务器选云采购——不阻塞开发，但阻塞上线。
2. **最大范围风险**：非网签双轨（Q3）——若非网签客户占比高，一期周期取 8 周上限。
3. **最大口径风险**：优惠三式（Q2）——记错账比没有系统更糟，口径未冻结前 P1-T08 不开工。
4. **数据迁移质量决定上线信任**：P0-T13 差异未清零不切系统。
5. **语音转单降级路径**：准确率不达标时降级为「转写文本 + 人工编辑」，业务流程不断。
