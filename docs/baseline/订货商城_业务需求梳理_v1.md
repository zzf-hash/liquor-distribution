# 酒类分销订货商城 · 业务需求梳理

> 版本 v1.0 · 2026-09-21
> 来源：①《业务流程全景 v1.0》（行业通用基线）② 订货商城五角色功能清单 ③ 内部流程 11 条（甲方口述版）
> 用法：本文为需求基线。后续拿商户实际业务逐条对照做「保留/简化/删除/新增」。

---

## 1. 系统定位

面向**酒类分销商**（夫妻店 <10 人 ~ 公司化 10~30 人）的一体化订货商城：

**订货商城（客户端） + 进销存（采购/仓储/配送） + 应收财务（对账/催收/销账） + 团队管理（拜访/绩效/工资）**

### 1.1 端划分

| 端 | 使用者 | 核心场景 |
|---|---|---|
| 客户小程序/商城 | 客户 | 自助下单（语音/照片/文字）、账期提醒、电子单据（未结一览、已结保留 6 个月） |
| 业务员移动端 | 业务员 | 跑店拜访、代下单、催收、陈列拍照、水印打卡、绩效进度、特单申请 |
| 内勤 Web 端 | 出纳/内勤 | 接单开单（语音复述式录入）、客户开户、收付款销账、工资/报表一键生成 |
| 仓配移动端 | 仓管/配送 | 收货入库（手动/拍照/语音/批次效期）、拣货出货、签收、退货、盘点 |
| 老板端 | 企业主 | 实时经营看板、五类审批、绩效设置、摄像头查看 |

## 3. 内部流程（11 条，系统化描述）

### F1 新客户开户
业务员开拓新店 → 录入档案（店名/位置/证照/老板电话/结算方式/账期天数/信用额度/价格/收货时段）→ 内勤确认 → 系统生成客户 → **老板确认**
- 系统点：档案字段模板、信用账户初始化、专属价生效时机（建议老板确认后才可下单，待确认）
- 涉及审批线 ①

### F2 接单履约（主线）
客户商城自助下单 或 业务员代下单 → 业务员确认（审单）→ 仓管/配送出货送货 →（**非网签客户**：连打印机打单）→ 客户点货签收 + 填写回包装品类（纸箱、周转箱）及数量 →（非网签客户留客户联）→ 纸质单据交内勤录入系统
- 系统点：审单自动预检四要素（客户有效/信用额度欠款、价格正确/专属价、库存可满足、达起送量）；网签/非网签双轨；回包装数量回填
- 异常：拒收（货回仓、订单状态回滚）、破损当场换/补/记账、客户不在（放邻居/改约/带回）、数量争议以签收凭证为准

### F3 商品采购（先付）
仓管报采购计划 → 内勤/出纳确认订货 → **企业主确认** → 内勤/出纳付款 → 到货 → 仓管清点卸货 → 仓管入库（批次+效期）→ 内勤/出纳确认
- 验收要素：数量/破损/生产日期/批次/赠品；每次进货可调价（联动 F7）

### F4 商品采购（后付）
仓管报计划 → 内勤/出纳确认订货 → 到货 → 仓管清点卸货 → 仓管入库 → 内勤/出纳确认 → **企业主确认** → 内勤/出纳付款确认
- 与先付的唯一差异：企业主确认节点在入库之后、付款之前

### F5 公司杂费报销（水/电/耗品/油费/车辆保险）
内勤/出纳采购与缴纳 → 上传单据或截图（费用台账，无审批节点）

### F6 公司运营费用报销（工资/房租/营销开支）
业务员/内勤提报（金额、时间、用途）→ **企业主审批**

### F7 调价
业务员/内勤提报（依据市场销售价及进货价）→ **企业主审批** → 内勤改价
- 联动：一键调价 → 存货增值/贬值处理 → 客户价联动

### F8 特单（零售/团购）
全员可下单（品名/数量/价格/配送时间/地址定位/联系人电话/收款人及收款时间）→ 内勤审批确定价格 → 仓管/配送出货
- ⚠️ 与角色清单「企业主特单审批」存在归属矛盾，见 §8-Q1
- 旁支：婚宴/宴席单（整单议价、送现场、余量退回、空瓶回收）

### F9 应收销账
业务员收款后 → 内勤/出纳录入 → 销账 → 系统发送清账通知给客户

### F10 退货销户
客户通知业务员退货 → 业务员到现场清点并填报退货单 → 客户确认签字 → 通知仓管/配送按退货单收货 → 仓管退货入库后确认（**数量只能改多不能少**）→ 内勤/出纳一键生成应收所有余款、与业务员共同催收 → 回款后内勤/出纳销户

### F11 无单回包装
全员根据客户要求下单 → 仓管/配送回库后确认
- 与 F2 的有单回包装互补：客户要求单独回收纸箱/周转箱的场景

## 4. 功能需求清单（分域 + 优先级）

> P0 = 首期主线；P1 = 二期管控效率；P2 = 三期 AI/延伸

### D1 客户域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 客户档案 | 店名/位置/证照/老板电话/结算方式/账期天数/信用额度/专属价/收货时段 | P0 |
| 开户流程 | F1 四步流程 + 老板终审 | P0 |
| 客户分级 | ABC 分级（按月贡献），级别→价格→拜访频率 | P1 |
| 信用控制 | 账期自定义 + 额度，超额拦单 or 老板特批（留痕） | P0 |
| 流失预警 | X 天未下单提醒 | P2【AI】 |
| 客户端能力 | 下单三式（语音/照片/文字）、账期自动提醒、未结单据一览、已结保留 6 个月 | P0 |

### D2 商品与价格域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 商品档案 | 品类（白酒/啤酒/红酒/洋酒/饮料）、规格（箱·瓶）整散换算、条码、度数、产地、品牌、供应商、首字搜索 | P0 |
| 价格链 | 成本价→供货价（一批）→二批价→终端供货价→零售指导价 | P0 |
| 一客一价 | 老客户/大客户议价，走审批线① | P0 |
| 调价流程 | F7 + 存货增值/贬值处理 + 客户价联动 | P1 |
| 优惠三式 | a. 随单赠 0-10 送 0-10（系统随单扣减）；b. 除瓶箱后 5%-50% 返利；c. 月/季/半年/年定扣货款 | P1 |
| 开瓶费 | 回瓶盖/不回瓶盖两种，不回瓶盖系统自动减 | P1 |
| 临时活动特价 | 限时促销需审批（价格引擎） | P1 |
| 陈列费/进店费 | 商超渠道固定费用台账 | P2 |

### D3 采购域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 采购计划 | 仓管报计划（历史动销/节日/客户预告/资金） | P1 |
| 双流程 | 先付 F3 / 后付 F4，审批节点位置不同 | P1 |
| 验收入库 | 数量/破损/生产日期/批次/赠品；入库录入手动/拍照/语音 + 批次效期 | P0 |
| 成本价录入 | 内勤录入，一键生成采购明细 | P1 |
| 补货建议 | 销量预测 + 安全库存 + 资金占用测算 | P2【AI】 |

### D4 订单域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 接单渠道 | 商城自助、业务员代下单、电话/微信（内勤录入）、语音复述式录入、厂家/平台转单 | P0 |
| 审单预检 | 四要素自动校验 + 业务员确认 | P0 |
| 拆并单 | 同客户多单合并配送；缺货拆单欠货登记 | P1 |
| 特殊单 | 赠品单、退货单、换货单（破损）、样品单、内部领用、婚宴定制、特单 F8 | P1 |
| 改单/取消 | 配送前拦截，配送中协商 | P1 |
| 欠单/白条 | 口头承诺先送后补单，**必须留痕** | P1 |

### D5 仓储域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 批次库存 | 批次+效期，拣货先进先出 | P0 |
| 拣货复核 | 拣货单→复核（错发漏发是客诉大头） | P0 |
| 盘点 | 周期抽盘 + 月末大盘，差异报损审批 | P1 |
| 库存预警 | 安全库存、临期预警（啤酒临期折价甩卖规则） | P1 |
| 库位 | 高值品上锁区 | P2 |
| 包装物资产 | 空瓶/纸箱/周转箱押金管理、瓶盖/拉环回收兑付 | P1 |
| 车销模式 | 装车=出库、移动仓、回仓盘入/报损/钱货核对 | P2〔模式可选〕 |

### D6 配送域
| 需求 | 说明 | 优先级 |
|---|---|---|
| 排线 | 固定路线制（周一东片…），客户知悉等货 | P1 |
| 临时插单 | 紧急单专送或搭线 | P1 |
| 签收 | 电子网签 / 打印留客户联 / 拍照/微信确认；回包装品类数量回填 | P0 |
| 异常处理 | 拒收回滚、破损补换、客户不在、数量争议以凭证为准 | P1 |
| 回收 | 空瓶/周转箱随车带回（F11 无单回包装） | P1 |

### D7 财务应收域
| 需求 | 说明 | 优先级 |
|---|---|---|

| 成本核算 | 移动加权平均（主流），批次价可调整 | P0 |
| 费用管理 | 杂费 F5 / 运营费 F6、油费路桥/车辆维修/装卸人工/水电/开瓶费支出 | P1 |

## 5. 关键业务规则库

| 编号 | 规则 |
|---|---|
| R1 | 价格五级链：成本→一批→二批→终端供货→零售指导；叠加 ABC 分级价与一客一价 |
| R2 | 信用双控：自定义账期天数 + 信用额度；超额**拦单**或老板特批（留痕） |
| R3 | 优惠三式：随单赠（0-10 送 0-10，系统随单扣减）；除瓶箱后 5%-50% 返利（月末核算，货补/票折）；月/季/半年/年定扣货款 |
| R4 | 退货入库数量：仓管可改**只能多不能少** |
| R5 | 回包装：签收时回填纸箱/周转箱品类数量；无单回包装全员可下、仓管回库确认 |
| R6 | 开瓶费两态：回瓶盖 / 不回瓶盖（系统自动减） |
| R7 | 成本核算：移动加权平均；批次价可调整；调价触发存货增值/贬值处理 |
| R8 | 单据：网签客户电子签收；非网签客户打印留客户联 + 纸质单据内勤回录；**已结款电子单据保留 6 个月** |
| R9 | 数量争议以**签收凭证**为准 |
| R10 | 绩效以**回款**计，非下单额 |

## 6. 实体模型草案（概览）

```
Merchant 商户（若 SaaS 多租户）
 ├─ User 员工（角色：企业主/业务员/内勤出纳/仓配）
 ├─ Customer 客户 ─┬─ CustomerPrice 一客一价
 │                 ├─ CreditAccount 信用（额度+账期+欠款）
 │                 └─ ABCLevel 分级（月贡献）
 ├─ Product 商品 ─ Spec 规格（箱瓶换算/条码）
 │              └─ Supplier 供应商
 ├─ PriceLevel 五级价 / PriceChange 调价单（审批⑤）
 ├─ Promotion 促销（随单赠/特价/临时活动） / Rebate 返利方案 / OpenFee 开瓶费 / DisplayFee 陈列费
 ├─ PurchaseOrder 采购单（先付/后付）─ Payment 付款单
 ├─ Inbound 入库单（批次+效期）─ BatchStock 批次库存（库位/押金物）
 ├─ SalesOrder 订单 ─ OrderLine 明细（含赠品、一客一价快照）
 │                 ├─ SpecialOrder 特单（地址/联系电话/配送时间/收款人及时间）
 │                 ├─ Delivery 配送单（排线）─ SignOff 签收单（网签/拍照/纸质 + 回包装回填）
 │                 └─ ReturnOrder 退货单
 ├─ PackageReturn 回包装单（有单/无单）
 ├─ Receivable 应收 ─ Receipt 收款核销 ─ eVoucher 电子单据（6 个月）
 ├─ Expense 费用单（杂费/运营费）
 ├─ Approval 审批单（5 类）
 ├─ Visit 拜访记录（八步骤/水印打卡/陈列照片/竞品信息）
 ├─ KPI 绩效方案 ─ Payroll 工资表（底薪+绩效）
 └─ StockTake 盘点单 ─ StockLoss 报损单
```

## 7. 非功能需求

- **实时性**：销售额/毛利/库存/员工进度实时可查（老板端）
- **单据留存**：已结款电子单据保留 6 个月，未结款永久可查
- **打印对接**：非网签客户 Web 端连接打印机打单（型号/协议待确认）
- **移动端**：业务员/仓配以移动端为主；内勤以 Web 为主
- **合规**：客户证照留存；不向未成年人售酒（标识 + 下单确认）
- **审批时效**：审批待办需消息推送（老板/内勤）

## 9. MVP 分期建议

**一期（主线跑通，P0）**
客户档案+信用拦截 → 商品+五级价+一客一价 → 接单（商城+代下单+内勤开单+审单预检）→ 批次库存出库 → 签收（网签+回包装回填）→ 收款销账+应收台账+账期提醒 → 老板四问看板 → 电子单据

**二期（管控+效率，P1）**
5 条审批线、特单、退货销户、回包装（含无单）、调价联动、采购双流程、盘点报损、优惠三式+开瓶费、绩效工资三件套（设置/进度/工资表）、月结对账、一键报表、非网签打印、拜访八步骤+水印打卡、语音/照片转单（AI 草稿+人工兜底）

**三期（AI 深化+延伸，P2）**
自动对账推送、流失预警、销量预测补货、路线优化、自然语言查账、摄像头、车销模式、婚宴/节日战役、陈列费台账

## 10. 价值高点与风险

**系统价值最高（优先做深）**
1. 信用超额拦截（资金命门）
2. 语音/照片转单草稿（接单效率，AI 承担口语容错）
3. 月结对账自动化（无系统时 1-3 天 → 分钟级）

**主要风险**
- 网签/非网签双轨并存的流程复杂度（Q3）
- 一客一价 + 优惠三式的数据治理（价格快照必须随单留存）
- 口语/手写识别准确率 → 用「可编辑草稿 + 人工确认」兜底
- 绩效以回款计的归属规则模糊（Q8）
