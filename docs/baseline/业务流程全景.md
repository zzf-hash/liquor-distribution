# 酒类分销商业务流程全景（行业通用参考版）

> 目的：把市面酒类分销商的通用业务流程整理成基线库。后续拿商户实际业务逐条对照，做加/减/改，完成适配。
> 标注说明：〔模式〕标注该流程受商户经营模式影响；〔高频〕〔低频〕标注出现频率；【AI】标注 AI 可介入点。

---

## 〇、角色与组织形态

| 角色 | 职责 | 备注 |
|---|---|---|
| 老板/老板娘 | 采购决策、大客户维护、资金、审批 | 小商户常身兼采购+销售 |
| 业务员（销售） | 跑店拜访、接单代下单、催收、陈列 | 按片区划分客户 |
| 内勤/开单员 | 电话微信接单、录单开单、对账、开票 | 商户神经中枢 |
| 财务 | 收付款、应收应付、毛利核算 | 小商户由内勤兼 |
| 仓管 | 出入库、批次效期、盘点 | 小商户由内勤兼 |
| 司机/配送员 | 送货、卸货、代收款、签收 | 常兼搬运 |

**组织形态两档**：
- 夫妻店型（<10 人）：一人多岗，流程混在微信+电话+本子上
- 公司化（10~30 人）：岗位分工明确，有制度但执行靠人盯

## 一、商品与价格管理

### 1.1 商品档案
- 品类：白酒、啤酒、红酒、洋酒、黄酒/保健酒、配套（饮料/水/香烟视执照）
- 属性：品名/规格（箱·瓶·提）/条码/整散换算/度数/产地/品牌/供应商
- 批次与效期：啤酒强效期（一般 6-12 月）、红酒批次、白酒批次（溯源）
- 高值品标记：名白酒需防盗防调包流程

### 1.2 价格体系〔核心复杂度〕
- 成本价 → 供货价（一批）→ 二批价 → 终端供货价 → 零售指导价
- 客户分级价：A 类（大超/连锁）/B 类（烟酒店）/C 类（餐馆）不同价
- 一客一价：老客户/大客户议价，记在老板脑子里〔迁移难点〕
- 调价：厂家调价通知 → 存货增值/贬值处理 → 客户价联动 → 报备

### 1.3 促销与返利（行业特色重点）
| 类型 | 说明 | 结算方式 |
|---|---|---|
| 随单赠 | 买 10 送 1，直接在订单体现 | 系统随单扣减 |
| 坎级返利 | 月累计达标返 2%-5% | 月末核算，货补/票折 |
| 季返/年返 | 与厂家/大客户的年度协议 | 协议核算 |
| 开瓶费 | 白酒特色：服务员按回收瓶盖/扫码兑付 | 按瓶盖数量兑现金【AI：扫码识别】 |
| 搭赠/特价 | 限时促销，需审批 | 价格引擎 |
| 陈列费/进店费 | 商超渠道固定费用 | 费用台账 |

## 二、采购与进货（供应商侧）

### 2.1 流程
```
需求汇总(业务员报量+补货点) → 采购计划 → 供应商比价/询价 → 采购单
→ 到货预约 → 验收(数量/破损/生产日期/批次/赠品) → 拒收/让步接收
→ 入库(批次+库位+效期) → 采购对账 → 付款(现款/账期/预付)
```
- 供应商类型：厂家直供 / 区域总代 / 二批补货（急货）/ 进口商（红酒洋酒，海关单证）
- 厂家返利核算：票折 / 货折 / 现金返，月度对账〔易错人工重灾区】【AI】
- 首次进货：新品试销、样品、厂家政策（首单优惠）
- 退供应商：临期退换、破损退换、滞销调货

### 2.2 补货决策〔模式：经验驱动〕
- 现状：老板拍脑袋 + 业务员报量
- 依据：历史动销 / 节日（春节前 1-2 月白酒压货、夏季啤酒旺季）/ 客户预告 / 资金
【AI：销量预测 + 安全库存建议 + 资金占用测算】

## 三、客户与终端管理

### 3.1 客户类型与特点
| 类型 | 特点 | 结算 |
|---|---|---|
| 烟酒店 | 单量小频次高，重价差和返利 | 现结~月结 |
| 商超/便利连锁 | 进店费+账期长+月结严 | 账期 30-60 天 |
| 餐饮（饭店/大排档） | 月结为主，开瓶费主战场 | 月结 |
| 酒吧/KTV | 洋酒啤酒量大，账期乱 | 周结~月结 |
| 团购/婚宴 | 整单议价，量大一次性 | 预付+尾款 |
| 二批商 | 大进大出，价低走量 | 现结为主 |

### 3.2 客户档案与信用
- 档案：店名/位置/证照/老板电话/结算方式/账期天数/信用额度/专属价/收货时段
- 客户分级：ABC 分级（按月贡献），级别→价格→拜访频率
- 信用控制：超额拦单 or 老板特批〔系统价值最高点之一〕
- 流失预警：X 天未下单提醒【AI】

### 3.3 拜访管理（业务员跑店）
- 标准八步骤：打招呼→查库存→理货/陈列→贴宣传→报单收订单→收款→记录→告别
- 拜访频率：A 类每周 1-2 次，B 类每周 1 次，C 类双周
- 拜访产出：订单、终端库存数据（铺货率）、陈列照片、竞品信息
【AI：拜访路线优化、终端库存推测补货建议】

## 四、接单与订单管理

### 4.1 接单渠道（并存）
1. 电话订货〔高频〕：内勤接听手记
2. 微信文字/语音〔最高频〕：客户发老板或业务员，口头转述
3. 小程序/商城自助：新潮商户
4. 业务员代下单：跑店现场或汇总
5. 厂家/平台转单：美团快驴、B2B 平台（部分商户）
6. **语音录入**：内勤 Web 端复述式录入（按住说话→实时转写）；业务员移动端语音代录
【AI：ASR 转写 + 消息结构化 → 订单草稿，价值最高。口语容错由 LLM 承担（别名/量词/「老价格」→专属价/来电反查客户），转写文本可编辑兜底】

### 4.2 订单处理
- 审单要素：客户有效（信用额度/欠款）、价格正确（专属价）、库存可满足、达起送量
- 拆并单：同客户多单合并配送；库存不足拆单欠货登记
- 特殊单：赠品单、退货单、换货单（破损）、样品单、内部领用、婚宴定制单
- 改单/取消：配送前拦截，配送中协商
- 欠单/白条：口头承诺先送后补单〔风险点，需留痕〕

## 五、仓储与配货

### 5.1 仓配模式（主流）
```
订单汇总 → 拣货单(批次先进先出) → 拣货 → 复核 → 装车 → 配送
```
- 拣货：按路线/按订单；啤酒与白酒分人搬
- 复核：件数+品项核对（错发漏发是客诉大头）
- 盘点：周期抽盘 + 月末大盘；差异（破碎、跑冒、鼠害、丢窃）报损审批
- 库存管理：安全库存/临期预警（啤酒临期折价甩卖规则）/库位（高值品上锁区）

### 5.2 车销模式（部分商户，啤酒/饮料常见）
- 装车=出库 → 巡线销售（车上即仓库）→ 当场收款 → 回仓
- 回仓处理：未售回库（盘入）、破损报损、钱货核对
〔模式差异点：车销商户的"库存"重心在车上，系统须支持移动仓〕

### 5.3 库存资产细节
- 空瓶/纸箱/周转箱：啤酒周转箱押金管理、纸箱变卖收入
- 瓶盖/拉环：开瓶费凭证回收兑付

## 六、配送与交付

### 6.1 排线与配送
- 固定路线制：周一东片、周二西片……客户知悉等货〔行业常态〕
- 临时插单：紧急单专送或搭线
- 装载核对：拣货复核后装车，司机签交接

### 6.2 到店交付
- 卸货 → 客户点数 → 签收（签字/拍照/微信确认）→ 当场收款（现结客户）
- 异常处理：
  - 拒收（关门/老板变卦）→ 货回仓，订单状态回滚
  - 破损当场换/补/记账
  - 客户不在 → 放邻居/改约/带回
  - 数量争议 → 以签收凭证为准
- 回收业务：空瓶/瓶盖/周转箱随车带回

## 七、结算与应收（资金命门）

### 7.1 收款方式
| 方式 | 场景 | 控制点 |
|---|---|---|
| 现结（现金/扫码/转账） | 烟酒店、二批 | 司机代收款当日交回，禁止坐支 |
| 周结/半月结 | 餐饮 | 定期跑收 |
| 月结（主流） | 商超、餐饮 | 月底对账后付款 |
| 预付/订金 | 团购、紧俏品（茅台） | 预收台账 |

### 7.2 月结对账流程〔最痛流程，无系统时 1-3 天〕
```
系统导出月度往来明细 → 与客户台账逐笔核对 → 差异处理
(漏单补录/价格争议/赠品口径/退货未冲) → 双方确认对账单
→ 约定付款 → 收款核销 → 发票(专票/普票)
```
【AI：自动生成对账单+微信推送客户确认+差异智能匹配】

### 7.3 应收与催收
- 账龄分析：30/60/90 天分级，超期预警
- 催收升级：业务员提醒 → 内勤对账催 → 老板上门 → 停货 → 法律
- 抹零/坏账：审批+留痕
- 费用冲抵：返利、开瓶费、陈列费与货款互抵〔易扯皮，须双方确认记录〕

## 八、财务与经营分析

- 成本核算：移动加权平均（主流）；批次价（红酒）
- 毛利分析：按品类/客户/业务员/单品；促销侵蚀毛利还原
- 费用：油费路桥、车辆维修、装卸人工、场地水电、开瓶费支出
- 老板关注：今日卖多少收多少、谁欠钱、什么货快没了、哪个业务员强
【AI：日报自动生成、自然语言查账】

## 九、合规与溯源

- 证照：营业执照（含酒类）、食品经营许可证、（部分地区）酒类流通备案
- 不向未成年人售酒（标识+下单确认）
- 进口酒：海关报关单、检验检疫证明随货
- 白酒溯源：批次管理、瓶码（防伪防窜货）
- 税务：开票需求（专票税点）、公私账分离（常见混乱点）

## 十、行业旁支场景（适配时逐条询问商户）

1. 婚宴/宴席单：整单议价、送宴席现场、余量退回、空瓶回收
2. 节日战役：春节/中秋前压货、节后调货退换、礼盒装
3. 窜货与区域保护：厂家限区销售，二维码追溯
4. 假货/调包纠纷：退换鉴定流程
5. 员工内购、样品领用、招待用酒
6. 多仓/门 市 部：前店后仓、分仓调拨
7. 挂账转承兑：商超承兑汇票回款

## 十一、适配维度（后续按商户裁剪的坐标系）

| 维度 | 选项 A | 选项 B | 影响 |
|---|---|---|---|
| 配送模式 | 仓配 | 车销/混合 | 库存模型、司机端功能 |
| 结算结构 | 现结为主 | 月结为主 | 应收模块深度 |
| 品类结构 | 白酒主导 | 啤酒主导/全品类 | 效期、溯源、返利复杂度 |

| 接单结构 | 电话微信 | 小程序自助 | 渠道端开发优先级 |
