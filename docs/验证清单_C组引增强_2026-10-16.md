## 1. 返利坎级阶梯 + 现金形式（M3-2）

| # | 命令 | 预期 |
|---|---|---|
| 1.1 | `GET /rebates/schemes?customerId=<C0004>` | seed 方案 `tiers=[{10000,0.02},{50000,0.05}]` |
| 1.2 | `POST /rebates/settlements/preview {"customerId":"<C0004>","period":"<上月或当月>"}` | 基数<1万时 `tierMissed:true, rate:0, rebateAmount:0`；先给 C0004 confirm 一笔 ≥1万 收款再预览 → `rate=0.02, tierHit=10000`；≥5万 → `rate=0.05` |
| 1.3 | 坎级未达标直接 `POST /rebates/settlements` | **409** 未达坎级最低门槛 |
| 1.4 | 新建方案 tiers 校验：`POST /rebates/schemes`（tiers 门槛非递增 / 某档 0.5%<br>→ 400） | 「门槛须严格递增」「每档费率 1%-50%」 |
| 1.5 | `POST /rebates/settlements {"settleType":"CASH",...}`（有基数客户） | 生成核算单 + `cashExpenseNo`；`GET /expenses?category=REBATE` 见「返利现金」费用单 **APPROVED**；`POST /expenses/<id>/pay` → PAID |
| 1.6 | 手工直建 REBATE 费用：`POST /expenses {"category":"REBATE",...}` | **400** 只能由月末核算生成 |

## 3. 毛利分析（M10-2）

| # | 命令 | 预期 |
|---|---|---|
| 3.1 | `GET /reports/gross-profit?month=<当月>&dimension=category` | totals.revenue≈当月签收实收额；rows 有品类行（含 profit/margin）；白酒类 revenue 含茅台专属价单 |
| 3.2 | `dimension=customer / rep / product` | 三维行数与月度报表客户/业务员/Top 商品对得上 |
| 3.3 | 口径抽查：`dimension=product` 中青岛行 cost>0（出库批次成本或回退成本价）；毛利=收入−成本 | 赠品行收入 0、成本计入（2.2 的订单拉低青岛毛利） |

## 4. 一键批量调价 + 客户价联动（M2-7）

|---|---|---|

## 已知边界
- 毛利成本口径：有出库记录按批次成本；无（历史/迁移单）回退最新 COST 价（caliber 字段明示）
- 随单赠同商品多规则取先命中一条；赠品单位跟随规则单位（默认箱）
- 客户价联动规则=价差平移（保持价差），COST 级不联动
- ASR 为一句话识别（≤60s）；密钥未配自动回退文字链路
