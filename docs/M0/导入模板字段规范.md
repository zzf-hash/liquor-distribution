## 1. 字段映射（模板列 → 实体模型 → 落库表设计预留）

## 2. 重复与冲突规则（预览校验器实现口径，P0-07 验收依据）

| 级别 | 规则 | 处置 |
|---|---|---|
| R-拒批 | 文件内主键重复（商品编码/客户编码/原始单据号/批次库存的编码+批次键） | 整批不写入（计划书 P0-07"导入失败不写入"），输出重复清单（行号+键值） |
| R-拒行 | 跨批与库内已有主键冲突 | 该行进差异报告，批次其余合格行可预览后分批提交 |
| R-拒行 | 必填缺失、枚举错值、日期格式错、金额负数、失效日<生效日、已收>应收、未收≠应收-已收 | 差异报告标注列+原因码 |
| R-拒行 | 外键缺失：价格/库存/应收引用的客户/商品编码不在同批且不在库 | 原因码 REF_MISS，提示先导主档 |
| R-警告 | 非现结客户无信用额度/账期天数；客户专属价无审批单号；啤酒品无真实批次；店名疑似重名（编辑距离≤2 或同手机号） | 进差异报告"待确认"类，商户逐条批注后可放行 |
| R-警告 | 全批盘点基准日不一致 | 升级为拒批（期初口径唯一性） |

提交顺序约束：**商品 → 客户 → 价格 → 期初库存 → 期初应收**（外键依赖链）。同一批次号（ImportBatch）内五类可分单提交，批次号支持整体回滚。

## 3. 差异报告（模板校验预览产物，对应计划书 M0-03 验收"无无法解释差异"）

- 形态：导入预览后导出 xlsx，三 sheet——`拒行清单`（行号/原值/原因码/建议动作）、`警告待确认`（商户填批注列）、`汇总`（总数/通过率/各原因码计数/期初三表合计与台账核对值）。
- 处理 SLA（随 §6.3 上线前 2 周冻结字段窗口）：拒行必须回源文件修正后重传整文件（不做行级修补，防版本漂移）；警告批注齐全即计入"已解释差异"。
- 出口判据（M0-03）：抽样 30 条与原始资料逐字段一致 + 差异报告零"无法解释"项 + 期初应收合计=商户台账合计（分毫一致，任务书 §5-4"差异未清零不切系统"）。

## 4. 抽样 30 条核验方案

- 分层抽样：商品 8 / 客户 8 / 价格 6 / 期初库存 4 / 期初应收 4；每类必含高值品、月结客户、纸单客户、啤酒批次、争议应收各≥1。
- 执行人：内勤（数据源比对）+ PM（复核签字）；比对源=现行台账/证照/微信记录原件。
- 结果记录在 `docs/M0/抽样核验-记录.md`（M0-03 收口件，随试点数据盘点填充）。

## 5. 回滚方案

| 场景 | 动作 | 依据 |
|---|---|---|
| 预览不通过 | 零写入，天然无回滚 | P0-07"导入失败不写入" |
| 批次提交后发现脏数据 | 按 ImportBatch 整批回滚：删除该批产生的主档/流水行，回滚前自动备份快照表；期初类回滚后必须重新执行全量盘点基准 | 计划书 §4.2"生产发布可回滚，数据变更需迁移脚本" |
| 切换后发现口径错误 | 禁止改导入行；红字调整单（盘点/报损/应收调整）走审批线修正，原导入流水不可变 | 计划书 §4.2"不得通过直接改余额或库存修复问题" |
| 上线观察期账实不符 | 降级纸单回录（§6.3 控制点），数据组核对差异→修正批次重导 | 计划书 §6.3 |

回滚演练：M1 试点环境（P0-04 完成后）至少执行一次"导入→回滚→重导"全程演练并留记录，作为 §6.3"备份可恢复"控制点的组成部分。

## 6. 导入前商户侧作业清单（内勤/财务，随模板发放）

1. 按模板列头整理台账，**保留原表另存**，不在原件上改。
2. 删除蓝色示例行；"编号"列没有就用"SKU0001/C0001/初0001"规则自造并登记对照表。
3. 冻结盘点时点（建议切换日月末 24:00），盘点基准日五表填同一天。
4. 每表负责人签字（商品/客户/价格=内勤；库存=仓管；应收=财务/老板），拍照随文件交回。
5. 存疑数据不要猜：填"迁移备注"留痕，等差异报告"待确认"类批注时处理。
